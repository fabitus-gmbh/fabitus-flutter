# fabitus_crud_api

Building blocks for talking to CRUD style REST APIs from Dart and Flutter
applications.

> Status: scaffold. The public API is not implemented yet.

## Installation

The package is not published on pub.dev. Depend on it via git:

```yaml
dependencies:
  fabitus_crud_api:
    git:
      url: https://github.com/fabitus-gmbh/fabitus-flutter.git
      path: packages/fabitus_crud_api
```

## Usage

```dart
import 'package:fabitus_crud_api/fabitus_crud_api.dart';
```

See [`example/`](example/) for a runnable example.
